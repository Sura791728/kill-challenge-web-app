# キルチャレ管理

VALORANTとAPEXの配信向けキルチャレンジ管理アプリです。[Webアプリを開く](https://valorant-kill-challenge-control.blue-sloth-0287.chatgpt.site)。

## 主な機能

- ユーザー名とパスワードで登録し、スマホとPCから同じ記録を操作
- 利用者・ゲームごとにパネル、ポイント換算、ギフト、ランク倍率を設定
- キルとパネルの加算・取り消し、操作を元に戻す・やり直す
- ランダムスターベイビー（小170 BC・中3,000 BC・大25,000 BC）とその他のギフトを個数で加算
- OBS用キルゲージ・パネル表示と表示URLの再発行

## アカウント

メールアドレスやChatGPTアカウントは不要です。新規登録時に表示される復旧コードを保存してください。パスワードを忘れた場合、復旧コードで再設定できます。パスワードと復旧コードの両方を失うと、そのアカウントの記録を復元できません。

以前のChatGPTログイン版の記録は自動では新しいアカウントに移りません。旧データは削除せずに残してあります。

## 開発と配置

このソースはChatGPT SitesのホスティングとCloudflare D1を使用します。GitHub Pagesにそのまま配置しても、アカウントや記録の保存は動きません。CloudflareのURLを入口にする手順は [cloudflare-proxy](cloudflare-proxy/README.md) を参照してください。自分用にアプリ本体を配置する場合は新しいデータベースも用意してください。公開ソースに利用者の記録や認証情報は含めていません。

```sh
node --experimental-strip-types tests/stream.test.mjs
npm run build
```

ソースコードの閲覧用公開です。ライセンスは指定していません。
